# 🤖 FR3 Manipulation Stack

> **A ROS 2 based manipulation stack for the Franka Research 3 (FR3) manipulator, bringing together kinematic analysis, trajectory generation, control, and motion planning into a modular robotics framework.**

---

## 🚀 Overview

The **FR3 Manipulation Stack** is a growing ROS 2 based framework developed for experimenting with and implementing different aspects of robotic manipulation using the **Franka Research 3 (FR3)**.

The stack is organized into modular ROS 2 packages, where each package focuses on a specific layer of the manipulation pipeline — from understanding the robot's reachable workspace to generating joint trajectories and performing motion planning.

## 🛠️ Implemented Modules

### 🔬 Workspace Analysis

Kinematic analysis and visualization of the **reachable workspace** of the FR3 manipulator.

### 📈 Joint-Space Motion

Joint trajectory generation and execution using configurable motion-generation methods, with **Gazebo-based simulation and visualization**.

### 🧭 MoveIt 2 Motion Planning

MoveIt 2 configuration for the FR3 using the **MoveIt Setup Assistant**, together with a custom **C++ MoveIt API** for motion planning and execution.
